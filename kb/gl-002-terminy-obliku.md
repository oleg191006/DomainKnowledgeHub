# GL-002. Терміни обліку

| Термін | Визначення | Синоніми |
|---|---|---|
| Книга надходжень | Документ первинної реєстрації предмета в музеї | КН |
| Інвентарна книга | Документ наукової інвентаризації предмета | інвентар |
| Одиниця обліку | Предмет або група предметів, зареєстровані під одним номером | облікова одиниця |
| Звірка наявності | Процедура підтвердження фізичної наявності предметів фонду | звіряння |
| Акт технічного стану | Документ, що фіксує стан предмета на дату огляду | акт огляду |
