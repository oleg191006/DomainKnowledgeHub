# Підказка 4. Незалежне оцінювання тверджень

Підказка складається з п'яти елементів: **роль**, **контекст**, **завдання**, **формат виходу**,
**правила**. Нижче — короткий опис кожного; повний текст, поданий моделі, збережено в журналі
`llm_log/session_03_judge.jsonl` (поле `raw` містить вихід, а `prompt_sha256` — хеш версії підказки).

## 1. Роль
Незалежний рецензент тверджень, який їх не писав.

## 2. Контекст
Модель читає файл `tmp/judge_items.txt` — 22 твердження без статусів, без confidence і без
коментарів людини. Це зроблено навмисно: будь-яка попередня оцінка в полі зору рецензента
зруйнувала б незалежність і знецінила κ.

## 3. Завдання
Для кожного з 22 тверджень — рівно одна оцінка `support / reject / uncertain` і обґрунтування
на 1–2 речення; для `reject` — вказати, що саме хибне.

## 4. Формат виходу
JSON-поле `judgements`: `[{"id","verdict","reason"}]`, рівно 22 елементи у порядку файлу.

## 5. Правила
1. Оцінювати самостійно, не підлаштовуючись під припущення, що більшість тверджень правильні.
2. Джерел не вигадувати.
3. Неточна числова межа — підстава для `reject`, навіть якщо решта твердження правильна.
4. `uncertain` — коли перевірка потребує внутрішніх даних установи, а не зовнішнього документа.

## Результат
Дві незалежні сесії (моделі A і B) → `claims/verification.csv`, κ Коена = 0,516.
