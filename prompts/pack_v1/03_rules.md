# Підказка 3. Правила IF–THEN зі структурованими умовами

Підказка складається з п'яти елементів: **роль**, **контекст**, **завдання**, **формат виходу**,
**правила**. Нижче — короткий опис кожного; повний текст, поданий моделі, збережено в журналі
`llm_log/session_03_rules.jsonl` (поле `raw` містить вихід, а `prompt_sha256` — хеш версії підказки).

## 1. Роль
Інженер знань, який пише правила для рушія прямого ланцюжкування.

## 2. Контекст
Чинні орієнтири передаються моделі явно: коридор 40–60 % RH і 16–25 °C, межа вогкості близько
75 % RH, освітленість близько 50 лк для високочутливих матеріалів і 150–200 лк для живопису.
Це зроблено навмисно: інакше модель підставляє застарілу норму 45–55 % з пам'яті.

## 3. Завдання
22 правила у структурованому вигляді: умови як масив `{slot, op, value}`, дії як масив рядків,
за потреби виняток, група, пріоритет 1–5 і рядок `rationale`. Імена слотів — латиницею й
узгоджені між правилами. Не менше 4 правил із винятками, не менше 3 — про нерухомі пам'ятки.

## 4. Формат виходу
JSON-поле `rules`: `[{"id","if","then","exception","group","priority","rationale"}]`;
оператори обмежені переліком `=, !=, >, <, >=, <=, in, contains`.

## 5. Правила
1. Джерел не вигадувати; власну межу позначати словом «припущення» в `rationale`.
2. Правила не дублюють одне одного.
3. Рівно 2 правила мають навмисно конфліктувати між собою — матеріал для аналізу конфліктів у ЛР 4.
