# Підказка 2. Групування правил за темами

Підказка складається з п'яти елементів: **роль**, **контекст**, **завдання**, **формат виходу**,
**правила**. Нижче — короткий опис кожного; повний текст, поданий моделі, збережено в журналі
`llm_log/session_03_rules.jsonl` (поле `raw` містить вихід, а `prompt_sha256` — хеш версії підказки).

## 1. Роль
Інженер знань, який формалізує практику зберігання у продукційні правила.

## 2. Контекст
Ті самі дані установи: покази датчиків, матеріал і техніка предмета, акти огляду, відвідуваність,
статус нерухомої пам'ятки, записи про втручання.

## 3. Завдання
Запропонувати 6 тематичних груп, на які розпадаються правила області; для кожної — коротка
назва і рядок пояснення. Групування виконується ПЕРЕД формулюванням правил, щоб правила
не збивались у одну тему.

## 4. Формат виходу
JSON-поле `groups`: `[{"id","name","note"}]`.

## 5. Правила
1. Групи не перетинаються за змістом.
2. Назва групи — іменникове словосполучення, не дієслово.
3. Жодна група не може називатися «Інше».

## Результат
Групування подано разом із правилами в одній сесії (`session_03_rules`), бо правила мають
посилатися на id групи.
